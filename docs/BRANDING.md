# 品牌方案（Branding）

> 本文档是 CodePocket 的品牌基石：命名逻辑、定位、口号与文案基调。
> 选定了其他名字？全局替换 `CodePocket`/`口袋码` 三处即可，其余内容通用。

---

## 1. 命名

### 推荐名：CodePocket「口袋码」

- **Code**：代码、编程、开发者基因；
- **Pocket**：口袋——手机就是随身的口袋，IDE 从此装进口袋；
- 中文「口袋码」：朗朗上口、有网感，一眼看懂"手机上的编程"。

### 备选名

| 名称 | 中文 | 记忆点 | 备注 |
|---|---|---|---|
| **CodePocket** | 口袋码 | 直白好记，域名可用性高 | **推荐** |
| PyDock | 码坞 | Python 谐音，"坞"=随身的家 | 更偏 Python 垂直 |
| PocketIDE | 掌中 IDE | 功能指向最清晰 | "IDE"一词较泛 |
| DevTerminal | 原项目名 | 已有历史 | 可作为英文代号保留 |

### 判断维度

- **好记**：中文两~三字，英文两词以内；
- **好搜**：避开 numpy、pycharm 等高权重词；
- **可扩展**：未来加 Java/JS 运行时，"Pocket 系列"依然成立（CodePocket 是"口袋里的编程"，不绑死 Python）。

---

## 2. 定位

> **一句话定位**：真正离线、开箱即用的安卓 Python IDE——手机上的现代开发环境。

- **给谁**：编程学习者、脚本写手、极客；需要在地铁/通勤/课堂上写点 Python 的人；
- **解决什么**：打开 App 就能写代码、跑代码，零下载、零网络、零广告、零订阅；
- **和竞品的区别**：装完即离线（对比 Termux 要装包、Spck 要联网）、现代 IDE 界面（对比 Termux 黑框）、开源免费（对比 Pydroid 付费）。

---

## 4. 关键词与话术基调

- **核心词**：离线、开箱即用、原生性能、现代界面、开源、无广告、无订阅；
- **基调**：诚实。不吹"预装 numpy"（实际未预装）、不吹"全平台"（当前仅 Android arm64）；
- **禁止**：夸大性能、暗示与商业产品等价、使用"最""第一"等极限词。

---

## 5. 视觉建议（待设计师落地）

- **主色**：延续 IDE 深色系（#1E1E2E 类底）+ 一个高亮 accent（青绿或琥珀）；
- **Logo 意象**：口袋剪影 + 代码光标 `|` / 大括号 `{}`；
- **图标语感**：方块圆角、扁平、与 Android 现代风格一致；
- **字体**：标题用几何无衬线（如 Inter / 思源黑体），代码展示用等宽（JetBrains Mono / Fira Code）。
