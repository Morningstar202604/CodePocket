# CodePocket 常见问题（FAQ）

---

## 安装与运行

**Q：APK 为什么这么大（约 124MB）？**
A：内置了完整的 CPython 3.13 原生运行时（`libpython3.13.so`）+ 标准库（纯 Python + C 扩展）。装完即离线，之后不需要下载任何东西。体积优化在路线图中。

**Q：安装时提示"未知来源"？**
A：在手机 设置 → 安全/隐私 → 允许安装未知来源应用（不同厂商路径不同）。

**Q：打开后一直"准备环境"？**
A：首次运行要解压标准库（约 1~5 秒），请稍等；若超过 30 秒仍未就绪，多半是 APK 被损坏或设备过于老旧，可重新安装试试。

**Q：支持哪些手机？**
A：Android 8.0+，ARM64 架构（目前市面绝大多数手机）。x86_64 模拟器支持在路线图中。

## 写代码与运行

**Q：`import numpy` / `pandas` 报错？**
A：当前版本未预装第三方科学计算库。这是文档曾误导的已知问题，已如实修正。离线安装 wheel 的能力在 v1.1 路线图中。

**Q：运行 .java 文件？**
A：当前仅支持编辑与语法高亮，运行能力未开放（会给出明确提示）。JVM 集成在路线图中。

**Q：脚本用 `__file__` 报 NameError？**
A：该问题已在 v1.0.0 修复（引擎注入 `__file__` 等模块属性）。升级到最新 APK 即可。

**Q：运行超时被中断？**
A：设置里可调超时秒数（默认 120s）。死循环保护默认开启。

**Q：点停止后提示"已有程序在运行中"？**
A：旧进程正在收尾（通常 2~3 秒），稍候重试。若持续出现，说明脚本未响应中断（如阻塞在不可中断的系统调用），请重启 App。

**Q：`print("a", "b")` 输出顺序错乱？**
A：不应出现。引擎做行缓冲保证一行内输出顺序正确。如遇请提交 Issue 附复现。

## 功能

**Q：AI 助手怎么用？**
A：设置 → AI 助手 → 填写 OpenAI 兼容端点（Base URL / API Key / 模型名）。代码只会发送到你配置的端点，不配置则零联网。

**Q：Git 支持哪些操作？**
A：init / commit / push / pull / 状态查看，基于 JGit，纯离线可用（push/pull 需要网络与仓库凭证）。

**Q：怎么导入导出项目？**
A：通过系统文件选择器（SAF），无需存储权限。导入 zip/文件夹，导出项目 zip。

**Q：会话恢复？**
A：App 会记住上次打开的项目与文件，重启自动回到编辑现场。

## 开源与贡献

**Q：这是什么协议？**
A：Apache-2.0，代码完全开源可审查。

**Q：怎么参与贡献？**
A：见 [CONTRIBUTING.md](../CONTRIBUTING.md)。修 bug、写文档、提 Issue 都可以。

**Q：测试报告说 11/11 通过，为什么还有 bug？**
A：`tools/test_suite.py` 驱动的是早期 Web 原型（Pyodide 时代遗留），未覆盖原生引擎。原生引擎的自动化测试在路线图中（[ROADMAP.md](ROADMAP.md)）。
